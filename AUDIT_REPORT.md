# Аудит кодовой базы «Тихий голос» (The Quiet Voice)

> **Этап 0 (Production Studio Audit)** · Базовая ревизия: `v1.0.0` · Виртуальное разрешение: `480×270` · Стек: React 19 + TypeScript + Vite 8 + Tailwind CSS 4 + Web Audio API + HTML5 Canvas 2D.

---

## 1. Общее состояние проекта

Игра представляет собой законченный вертикальный срез 2D pixel-art психологического хоррора с прологом на трассе, ночным лесом, пятиэтажным домом (23 комнаты), сборкой Эхо-4 (8 узлов), 6 головоломками, 10 тайниками, 20 записками (12 основных + 8 архивных), 4 аудиокассетами, 4 радиосигналами, 6 объектами детального осмотра и 3 концовками (`awakening`, `liberation`, `last_record`).

Сильные стороны:
- Отделённая от React симуляция (`src/game/engine/GameLoop.ts`, `GameRuntime.ts`, `controllers/simulationStep.ts`).
- Событийная шина (`eventBus.ts`), модульные системы (`systems/*`), версионированная миграция сохранений (`saveMigration.ts` `v1 → v4`).
- Встроенный валидатор контента (`contentValidator.ts`) и 47 проходящих автотестов (`audit.test.ts`, `rules.test.ts`, `e2e.test.ts`).

Вместе с тем при глубокой ревизии выявлены **критические и высокоприоритетные проблемы** в логике ИИ Тени, управлении, десериализации сохранений, цикле рендеринга, архитектуре монолитов и сборочном контуре.

## 4. Порядок реализации

Работы выполняются последовательно без удаления существующих локаций, предметов, загадок, сцен, кассет, записок и концовок:
1. Исправление P0/P1 критических багов (`InteractionSystem`, `PuzzleSystem`, `App.tsx`, `SaveSerializer`, `GameLoop`, `EventBus`, `GameRuntime`).
2. Очистка зависимостей и сборочного контура (`package.json`, `.github/workflows/ci.yml`, удаление неиспользуемого мусора).
3. Граф прогрессии и формальная валидация в `contentValidator.ts`.
4. Улучшение `HorrorDirector` (Event Scheduler с весами/бюджетом/группами) и ИИ Тени.
5. Модуляризация `renderer.ts` → `src/game/renderer/*`, оптимизация градиентов и частиц, доработка анимаций.
6. Модернизация `audio.ts` (6 шин + адаптивная музыкальная текстура + `playUiSfx` + `dispose`).
7. Полировка UI/UX, пазлов, подтверждений в паузе, доступности, геймпада и сенсорного управления.
8. Расширение тестов, нагрузочная проверка, финальная сборка и публикация `RELEASE_REPORT.md`.
