1. ПАСПОРТ ПРОЕКТА, СТЕК И СТРУКТУРА ФАЙЛОВ
--------------------------------------------------------------------------------
Название:          «Тихий голос» (The Quiet Voice)
Жанр:              2D Side-View Psychological Horror / Mystery / Exploration
Язык:              Русский
Архитектура:       Клиентское SPA (без обязательного сервера), localStorage
Базовое разрешение:480 x 270 px (HTML5 Canvas 2D, imageSmoothingEnabled = false)
Частота симуляции: Фиксированный шаг 60 Гц (FIXED_STEP = 1/60 с)

Стек технологий:
- React 19.0.1, ReactDOM 19.0.1
- TypeScript 7.0.2
- Vite 8.3.0
- Tailwind CSS 4.3.3 (@tailwindcss/vite)
- lucide-react 0.546.0
- Web Audio API (100% процедурный синтез, 0 внешних аудиофайлов)
- Автотесты: npm test (tsx --test src/game/*.test.ts)

Скрипты (package.json):
- npm run dev     -> vite --port=3000 --host=0.0.0.0
- npm run lint    -> tsc --noEmit
- npm test        -> tsx --test src/game/*.test.ts
- npm run build   -> vite build
- npm run preview -> vite preview

2. ИГРОВОЙ ЦИКЛ, КОНТРОЛЛЕРЫ И ШИНА СОБЫТИЙ
--------------------------------------------------------------------------------
Игровой цикл (App.tsx + simulationStep.ts):
- Фиксированный шаг симуляции FIXED_STEP = 1/60 с.
- Аккумулятор ограничен сверху до FIXED_STEP * 6 (максимум 6 подшагов за кадр),
  что исключает рывки физики после сворачивания вкладки.
- Ошибки игрового цикла не скрываются: фиксируются в GameDiagnostics
  (буфер с дедупликацией, длительность кадра, счётчик медленных кадров >50 мс).
- При потере фокуса (blur / visibilitychange) зажатые клавиши очищаются.
- При открытом модальном окне (activeOverlay !== 'none') симуляция мира и
  таймер playTimeSeconds ставятся на паузу.

Шина событий (GameEventBus, src/game/eventBus.ts) — 12 типизированных событий
с активными подписчиками (src/game/systems/eventListeners.ts):
 1. room:entered        { roomId, floor }
 2. part:collected      { partId }
 3. part:installed      { partId, installedCount }
 4. note:collected      { noteId }
 5. tape:collected      { tapeId }
 6. secret:discovered   { secretId }
 7. puzzle:solved       { puzzle: 'clock'|'safe'|'terminal'|'breaker'|'radio' }
 8. inspect:opened      { inspectId }
 9. player:hide_changed { isHiding, spotId }
10. shadow:event        { kind: 'spawned'|'startled'|'evaded'|'guide', floor }
11. ending:reached      { endingId }
12. save:persisted      { timestamp }

Контроллер диалогов (dialogueController.ts):
- Спикеры: thought, robot, system, radio, tape.
- Скорость печати (TextSpeed): slow = 26, normal = 46, fast = 82 симв./сек.
- Во время печати воспроизводятся голосовые блипы (soundEngine.playVoiceBlip).
- Первое нажатие пропуска раскрывает строку мгновенно, второе — переходит далее.

3.1. Зона 1 — Автомобильный пролог (car_prologue)
- Фаза driving:
  Управление: D/вправо (+0.55), A/влево (-0.25), Space тормоз (-0.85).
  Скорость: 0.35..1.85.
  При distance >= 0.36 -> radioBroken = true, помехи автомагнитолы.
  При distance >= 0.72 -> переход в фазу sputtering (стук, мигание фар).
- Фаза sputtering:
  Замедление (-0.48/с), мерцание фар. При speed <= 0.02 -> фаза stalled.
- Фаза stalled:
  [E] — попытка завести двигатель (ignitionAttempts).
  [W] — выход из машины в зону forest (x = 105, y = 216).

4. ФИЗИКА ПЕРСОНАЖА, ФОНАРИК И УПРАВЛЕНИЕ
--------------------------------------------------------------------------------
Движение и выносливость (rules.ts):
- WALK_SPEED = 66 px/s, RUN_SPEED = 108 px/s, присед = 0.55 * WALK_SPEED
- ACCEL_RATE = 520, BRAKE_RATE = 380
- Стамина (0..100): расход при беге 28/с, восстановление 18/с (в укрытии x1.15)
- Истощение (exhausted): при stamina <= 0.5, снимается при stamina >= 28

Фонарик:
- Старт: hasFlashlight = false, flashlightBattery = 100%, batteries = 1 шт.
- Расход во включённом состоянии: -0.55% / с
- Аварийный резерв: минимум 12% (никогда не гаснет полностью — нет софтлока)
- Перезарядка [R]: тратит 1 запасную батарейку -> 100% (если заряд < 94%)

Управление клавиатурой по умолчанию (переназначается в Настройках):
- left       : KeyA      (алиас ArrowLeft)
- right      : KeyD      (алиас ArrowRight)
- up         : KeyW      (алиас ArrowUp)
- down       : KeyS      (алиас ArrowDown)
- run        : ShiftLeft (алиас ShiftRight)
- interact   : KeyE      (в диалогах также Enter / Space)
- flashlight : KeyF
- reload     : KeyR
- inventory  : Tab       (алиас KeyI)
- journal    : KeyJ
- map        : KeyK      (алиас KeyM)
- пауза/выход: Escape

Сенсорное управление (TouchControls.tsx):
- Автоопределение через (pointer: coarse) + тумблер в Настройках.
- Элементы: горизонтальный виртуальный аналоговый джойстик с захватом касания
  и мёртвой зоной, Бег, Присед, Действие, Свет, Батарейка, Инвентарь, Журнал
  (с точкой непрочитанного), Пауза.
- Настройки: размер (small | medium | large) и раскладка (standard | swapped).

  v1 -> v2 -> v3 -> v4; deserializeGameState проверяет границы координат зон и
  этажей, валидирует списки по каталогу и исключает невозможные состояния.
